# Support

MCflare support is handled through GitHub Issues.

Before opening an issue, check:

1. [FAQ](docs/FAQ.md)
2. [Installation](docs/INSTALLATION.md)
3. [Choose your setup](docs/SETUP_CHOICES.md)
4. [Compatibility](docs/COMPATIBILITY.md)
5. [Troubleshooting](docs/TROUBLESHOOTING.md)

A useful support report includes Minecraft version, loader/platform version, MCflare artifact/version, whether the route is Orange/Tunnel/ordinary-direct, and the smallest relevant log excerpt.

MCflare v1 covers Minecraft's own Java connection. Voice-chat UDP, web maps, arbitrary mod side sockets, generic TCP/UDP tunnelling, VPN/WARP setup, and general Cloudflare account administration are outside project scope.

For security-sensitive reports, use [SECURITY.md](SECURITY.md) instead of posting exploit details or credentials in a normal issue.
